## Jetpack Compose App :rocket:

Jetpack Compose in Android :robot: provides a range of built-in composables that simplify UI development. 
This app aims to get knowledge of some foundational building blocks for UI development in Compose.

This codebase focuses on demonstrating :eyeglasses: the following Android UI elements and components using **Jetpack Compose:**

- Buttons
- Shapes
- Multiple TopAppBars
- Normal, Steps, and Range Sliders
- Cards, Chips, and CheckBoxes
- TextFields, Text, and Gradients
- Vertical and Horizontal Lists
- Images and Icons
- Bottom Navigation Bar
- Navigation Component

## About the App

A static app called Foodou is included in this repository. The app incorporates most of the components mentioned above, showcasing how declarative UI elements work together to create a cohesive interface.
The primary goal is to help other developers understand how to render apps effectively using Jetpack Compose and to visualize the potential of combining different UI elements.
